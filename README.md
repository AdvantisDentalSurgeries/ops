# Dental Surgery Operations System

Requirements analysis and domain model design for a dental surgery operations system (ADS) used by an Office Manager to manage dentists, patients, and appointments.

## Files

- `spec.md` — Original problem statement and task requirements
- `analysis.md` — Functional requirements (FR1–FR16) and domain model class descriptions
- `uml.md` — PlantUML source for the domain model class diagram
- `uml.png` — Rendered domain model class diagram
